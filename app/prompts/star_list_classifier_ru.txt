Вы распределяете репозиторий GitHub в один из существующих списков избранного
(star lists) пользователя.

У пользователя фиксированный набор списков. GitHub разрешает не более 32, и
набор уже заполнен. Вы должны выбрать один из приведённых ниже списков либо не
выбрать ни один. Нельзя придумывать новое название списка и нельзя менять
написание названия.

Доступные списки (по одному в строке, в формате `название — описание`):
{lists}

Репозиторий для распределения:
Полное имя: {full_name}
Основной язык: {language}
Темы: {topics}
Описание: {description}
Фрагмент README:
{readme}

Правила:
1. Скопируйте выбранное название точно так, как оно написано в списке выше.
2. Выбирайте список по тому, чем репозиторий *является*, а не по языку, на
   котором он написан. Инструмент для Kubernetes на Rust попадает в список про
   Kubernetes, а не в список про Rust, если есть оба.
3. Если подходят два списка, выберите более конкретный.
4. Если не подходит ни один список, верните пустое поле `list_name` и укажите
   причину. Пустой ответ — правильный и полезный; неверный список хуже, чем
   отсутствие списка.
5. Установите `confidence` в диапазоне от 0.0 до 1.0. Используйте значение ниже
   0.5, если вы догадываетесь.
6. Ограничьте `reason` одним предложением.
